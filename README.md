# Yeti Quest

## Опис проєкту

**Yeti Quest** — адаптивний вебсайт про пошуки снігової людини, дослідницькі експедиції та загадкові докази її існування. Сайт містить головну сторінку, розділи «Експедиції», «Докази» та «Про проєкт». Реалізовано інтерактивні елементи, зокрема фільтрацію доказів і перегляд матеріалів.

**Технології:** HTML, CSS, JavaScript, Webpack. Макети створено у Figma.

**Макет у Figma:** [Yeti Quest — Web Design](https://www.figma.com/design/zBkaUjRdXLhHhlRC0MTgn9/Yeti-Quest---Web-Design?t=nIcM77XG5HE8C21J-1)

## Розподіл обов’язків у команді

- **Відповідальна за дизайн** — розробка UI/UX-концепції, десктопних і мобільних макетів у Figma, вибір кольорів, типографіки та структури інтерфейсу.
- **Відповідальна за верстку** — створення HTML-структури сторінок, CSS-стилів та адаптивної верстки за макетами.
- **Відповідальна за програмування** — реалізація JavaScript-функціональності та інтерактивної взаємодії з елементами сайту.

## Інструкція із запуску

1. Встановити **Node.js** (із npm).
2. Завантажити репозиторій і відкрити папку проєкту в терміналі.
3. Встановити залежності:

   ```bash
   npm install
   ```

4. Запустити локальний сервер:

   ```bash
   npm start
   ```

5. Відкрити адресу, вказану в терміналі (зазвичай `http://localhost:8080/`).
