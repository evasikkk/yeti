# Change Log — Yeti Quest

## Change Request — зміна композиції інтерфейсу

**Пропозиція замовника:** відмовитися від модульної сітки, повернути текстові блоки та зображення на 5–10° і частково накласти їх один на одного.

**Рішення команди:** відхилено.

**Обґрунтування:** запропоновані зміни ускладнюють сприйняття інформації, порушують візуальну ієрархію та створюють ризики для адаптивності й доступності інтерфейсу відповідно до WCAG 2.1.

Для перевірки пропозиції створено альтернативні десктопні та мобільний макети у Figma. Зміни не впроваджувалися на сайті.

Детальний аналіз рішення наведено в документі «Обґрунтування відмови від зауваження.docx».
